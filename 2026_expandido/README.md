# Template de Resumo Expandido em LaTeX

Este diretório contém um template em LaTeX para produção de resumo expandido, com estilo acadêmico, bibliografia em `biblatex`, suporte a figuras, tabelas e estrutura de trabalho científico.

As instruções gerais de instalação e compilação estão no [README principal](../README.md).

Estrutura principal:

- `main.tex` — arquivo principal do documento
- `estilo.sty` — estilo e configurações do template
- `referencias.bib` — arquivo de referências bibliográficas
- `figs/` — pasta para imagens e elementos visuais
- `Makefile` — automação para compilar o documento

## Especificidades do template

- O resumo expandido deve possuir de 3 a 5 páginas.
- O texto deve apresentar problema ou questão investigativa, objetivos, metodologia, resultados e conclusões, de forma estruturada e articulada.
- O template oferece seções para introdução, desenvolvimento, fundamentação teórica, metodologia, resultados e discussão, considerações finais e referências.
- Use `referencias.bib` para cadastrar as referências e cite-as no texto. A bibliografia é processada com `biblatex` no estilo ABNT.
- A pasta `figs/` pode armazenar imagens e o cabeçalho visual do documento.
- O modelo oferece exemplos de figuras, tabelas, algoritmos, fórmulas, citações e disponibilização de materiais complementares.
- Relatos de experiência exclusivamente descritivos devem ser submetidos como resumo simples.

## Observação

Este template foi preparado para trabalhos com características de investigação científica. Antes da submissão, remova as orientações coloridas do modelo e revise o conteúdo, as referências e os elementos de identificação.
